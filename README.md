# Forever Macro Manager

A macro-editor companion for World of Warcraft: Forever.

The first planned release, **0.1.0**, adds a cheat-sheet panel beside Blizzard's
macro editor, with general macro reference and druid/healer examples.

Versioning uses Changesets: features increment minor, fixes increment revision
(`patch`), and major increments require Dylan's explicit direction.

CurseForge publishing is not configured. This addon will use a separate project
from Forever Radial Bars.
